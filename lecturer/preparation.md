# Подготовка к первому дежурству

## Что уже есть, а что требует отдельного шага

| Часть | Состояние площадки | Как проверить |
|---|---|---|
| Данные и shell-демо | Готовы к локальному запуску | `./setup` |
| Проверка учебной строки | Готова, локально | `./check --local` |
| Docker-обёртка | Есть; Docker и образы не устанавливаются | Отдельные шаги ниже |
| Настоящий myITMO | Не нужен, события вымышлены | Никаких сетевых обращений |
| Официальный checker и CI | Не подключены | Согласовать отдельно с курсом |
| Слайды и резервная запись | Есть мысли для слайдов в runbook, готовых медиа нет | Подготовить до занятия |

`./setup` не устанавливает Git, Bash, Docker и другие пакеты. Успешный локальный
PASS подтверждает контракт hello.txt, а не готовность всего курса.
Если команда сообщает `Docker is unavailable`, не повторять её на занятии:
программа не найдена в той оболочке, где идёт запуск.

## Репетиция без Docker — можно начать сейчас

Войти в папку своей копии. Имя может быть `os-lite-l0` или `os-lite-h0`:
в командах занятия важен корень репозитория, не имя папки.

```bash
bash
export LC_ALL=C TZ=UTC
PS1='demo $ '
./setup
./check --local
```

Если setup обнаружил работающий генератор, сначала остановить его в той оболочке,
где он запущен. Если hello.txt уже изменён, сохранить свою версию перед возвратом
к демо-строке: `printf 'Hello, OS Lite!\n' > src/hello.txt`.

Ожидаемые данные после reset: 10000 строк, 5 ERROR, рейтинг 3/1/1.
Сверить с expected-output.md. Пройти команды runbook в том же терминале,
в котором будет занятие. Особенно проверить пути с пробелами и остановку генератора.

На экране: шрифт 20–24 pt, короткий prompt, слайд/терминал рядом.
Проверить читаемость с расстояния и переносы строк. Если половины экрана мало,
показывать терминал на весь экран во время конвейера. Отключить уведомления.
Не выводить README с разгадкой перед расследованием.

## Docker — отдельная готовность до полной H0

Docker должен быть установлен и доступен **в том окружении, где запускается check**.
Docker на macOS не означает автоматически наличие команды внутри Ubuntu-машины.
Установку/интеграцию выполнить отдельно по инструкции для выбранного окружения;
этот репозиторий не меняет системные пакеты и права пользователя.

Проверить до лекции:

```bash
command -v docker
docker info
```

Если первый шаг не проходит — нет доступной команды. Если второй не проходит —
клиент есть, но движок недоступен или нет доступа. Не считать среду готовой.
После исправления, с сетью до пары:

```bash
docker pull alpine:3.20
docker pull hello-world
docker run --pull=never --rm hello-world
./check --docker
```

Затем отрепетировать FAIL → восстановление → PASS из runbook и пример h0-debug.
Не удалять посторонний контейнер ради освобождения имени; заранее выбрать свободное
имя и использовать его последовательно. Сохранить запись успешного прогона.

На занятии сеть для этих запусков не требуется: образы уже локальны, стоит
`--pull=never`. Если полного прогона и записи нет, использовать локальный маршрут
runbook и явно назвать его репетицией shell-части. Docker остаётся незакрытой
частью полной H0, а не «успешно показанным локально».

## Что отобрано из двух исходных документов

Сохранены: split-screen, одна мысль на слайд, потоки до кодов возврата,
поэтапный конвейер, прогноз до Enter, кавычки, живой лог, скрипт как готовый артефакт,
короткий Docker-блок и упражнения. Ранний Docker-PASS оставлен только при готовой среде.

Сокращены: обзор справки и истории, окружение и export, строгий режим.
Перенесены дальше: циклы, сложные glob/regex, awk/sed, /proc, сборка образов,
namespaces/cgroups, подробная настройка SSH и Docker.

Вместо абстрактного сервиса — согласованный учебный инцидент myITMO.
Сквозным является расследование внутри H0; настоящего сервиса для всего семестра
эта версия не обещает. Десять строк — учебный масштаб, а не производственная нагрузка.

## Критерий готовности ведущего

Без импровизации пройти расследование и назвать ожидаемые результаты.
Уложить shell-часть в 63 минуты с вопросами аудитории. Для полной H0 отдельно
успешно пройти Docker-блок за 12 минут на этой же машине. Ссылки курса и дедлайны
подставить до занятия; их нет в комплекте.
